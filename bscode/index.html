Download for Apple silicon ↓ v0.2.5 release notes

First launch on macOS

Move BsCode to Applications, then run:
xattr -dr com.apple.quarantine "/Applications/BsCode.app"

01 · Direct

Start four agents without opening four terminals.

Give each agent its own task, model, and session. Send a follow-up to one agent or address the room from the shared command bar.

02 · Follow

Know what is happening before a terminal stops.

Live output, checklists, status, and ETA stay attached to the agent doing the work. Finished sessions settle to idle instead of disappearing.

03 · Move

Local and SSH workspaces keep the same rhythm.

Open a project on your Mac or connect to a remote machine. Files, tabs, sessions, connection state, and generated outputs remain in one predictable layout.

04 · See

Change the view. Keep the work.

Switch from dense terminals to Cinematic mode or the Pixel tower without restarting a session. Every view reflects the same agents and the same live state.

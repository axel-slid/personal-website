02

Parallel work without parallel confusion.

Each agent gets a real terminal, deterministic identity, live task, state, checklist, ETA, and relevant-file history. The project remains one place even when the work splits four ways.

03

Focus changes. Context does not.

Press ⌘K for the full-screen Cinematic wall. The same sessions remain alive underneath, while one shared command dock routes follow-ups to a selected active agent.

04

A spatial view of the same live system.

Pixel mode assigns agents to tower floors. Move with the arrow keys, jump to an agent from the clipboard, or click a pet to see its RPG-style stats without interrupting the work.

Give every agent a place to work.

Abstract

Brains appear to spend energy selectively: predicting routine input, amplifying surprise, updating memory when it matters, and replaying useful traces. This project translates that idea into a model-level state packet rather than a biological claim.

A Predictive-Budget Neuron carries content, a local prediction, a signed residual, an eligibility trace, and a slow compute budget. The residual gates refinement, memory writes, and—in carefully tested settings—conditional execution. I test the same mechanism across irregular temporal streams, public MNIST, a ConvNeXt-style vision model, and a pretrained Swin V2-Tiny backbone.

The result is mixed by design: temporal state updates show a repeatable gain, while the three-seed Swin V2 pilot does not improve accuracy and is slower. The page is an evidence log, not a leaderboard claim.

Method

01

Predict

Estimate the next local state before spending a full update.

\(p_t = f_p(h_{t-1})\)
02

Measure surprise

Use the residual as a control signal, not only as a loss term.

\(\delta_t = x_t - p_t\)
03

Spend selectively

Refine, write, or replay when error and budget justify the cost.

\(g_t = \sigma\!\left(\alpha(|\delta_t|-\theta)\right)\)

Prediction turns surprise into compute.

The central design move is to make a biologically motivated signal operational: routine input follows a cheap path; surprising input earns refinement, memory writes, or replay.

PBN (ours). A single state packet carries content, prediction, residual, eligibility, and a slow budget. The gate is an algorithmic control signal inspired by sparse biological updating—not a claim that the implementation reproduces cortical circuitry.

Accuracy is held-out fraction correct. Active updates are algorithmic proxies for how often the expensive branch fires. Latency is wall-clock time for the stated implementation, not a hardware-independent energy measurement.

What the experiments say

POSITIVE · PBN (OURS)

Temporal memory is the strongest fit.

On public MNIST row streams, PBN (ours) reached 85.4% under missing rows vs 83.7% for GRU across five seeds, with a smaller parameter count.

BOUNDARY

Swin V2 did not improve yet.

Across three seeds, PBN-Swin was 97.35% clean vs 97.63% for dense Swin and was about 20% slower. The negative result stays visible.

NEXT FALSIFIER

Measure fused execution.

The active-update fraction is only a proxy. A real claim needs fused kernels, bytes moved, latency, and joules at equal accuracy.
